# ProMap Sim — 프로젝션 매핑 3D 시뮬레이터

프로젝션 매핑 설치를 **사전 설계**하기 위한 웹 기반 3D 시뮬레이터입니다.
환경(공간)에 따라 프로젝터의 **대수·위치·기종·렌즈 세팅**을 검토하고,
투사거리·화면 크기·픽셀 밀도·표면 조도 같은 실무 지표를 실시간으로 확인할 수 있습니다.

MadMapper / HeavyM 같은 매핑 소프트웨어와 Barco·Epson 등의 스로우 거리 계산기를
참고하되, **설치 전 단계의 공간 시뮬레이션**에 집중하고 누구나 바로 쓸 수 있는
쉬운 UI를 지향합니다.

## 실행 방법

```bash
npm install
npm run dev     # 개발 서버 (기본 http://localhost:5173)
npm run build   # dist/ 에 정적 빌드 — 아무 웹서버에나 올려서 사용 가능
```

## 주요 기능

### 1. 환경(공간) 프리셋
| 프리셋 | 용도 |
|---|---|
| 실내 벽면 | 회의실·전시실 벽면 매핑, 방 크기 조절 |
| 건물 파사드 | 미디어 파사드 — 돌출 구조물에 의한 그림자(차폐)도 시뮬레이션 |
| 곡면 스크린 | 원통형 곡면(반경/각도/높이 조절) 멀티 프로젝션 |
| 무대 + 오브젝트 | 큐브·구·원기둥 등 입체물 오브젝트 매핑 |

좌측 패널에서 공간 치수와 **주변광** 수준을 조절할 수 있습니다.

### 2. 프로젝터
- 최대 8대 배치, 기종 프리셋(XGA 4,000lm ~ 4K 20,000lm, 초단초점 포함) 또는 커스텀 사양
- **스로우비(줌), 수직/수평 렌즈 시프트(오프축 투영), 팬/틸트/롤** 지원
- 기즈모로 드래그 이동/회전 (`W` 이동, `E` 회전), 클릭 선택, `Ctrl+D` 복제
- "타깃 정조준" 버튼으로 주 투사면 중심 자동 조준

### 3. 투사 시뮬레이션 (셰이더 기반)
- 실제 투사 카메라 행렬로 표면에 테스트 패턴(그리드/화이트/컬러바) 투사
- 프로젝터별 **깊이맵 비교로 차폐(그림자) 처리** — 구조물 뒤 그늘 영역 확인 가능
- 입사각(코사인)과 거리에 따른 밝기 감쇠 반영
- **에지 블렌드 램프** 토글 — 중첩 구간의 블렌딩 결과 미리보기

### 4. 분석 모드
- **투사**: 실제 보이는 영상 미리보기 (주변광 대비 체감 밝기)
- **커버리지**: 영역별 커버 대수 표시 — 녹색 1대 / 황색 2대(블렌드 구간) / 적색 3대+
- **조도**: 표면 조도(lux) 히트맵

선택한 프로젝터의 **투사거리, 화면 크기(m), 픽셀 밀도(px/m), 표면 조도(lx),
체감 명암비**가 우측 패널과 하단 상태바에 실시간 표시됩니다.

### 5. 세팅 도우미 (자동 대수 산출)
투사면 크기, 기종, 목표 픽셀 밀도, 주변광 환경, 블렌딩 오버랩(%)을 입력하면:
- 필요한 **행 × 열 구성과 총 대수**
- 권장 투사거리(공간 깊이 초과 시 줌 보정 또는 경고)
- 달성 픽셀 밀도 / 표면 조도 / 명암비 등급
- 부족할 때의 개선 가이드(고해상도·고휘도 기종, 스택 등)

를 산출하고, **버튼 한 번으로 3D 장면에 자동 배치**합니다.

### 6. 프로젝트 저장
- 브라우저 localStorage 자동 저장
- JSON 파일로 저장/불러오기 (툴바)

## 계산 기준 (전문 지표)

| 지표 | 산식 |
|---|---|
| 화면 폭 | `투사거리 ÷ 스로우비` |
| 픽셀 밀도 | `가로 해상도 ÷ 화면 폭` (px/m) |
| 표면 조도 | `루멘 ÷ 화면 면적` (lx) — 스크린 게인 1.0 기준 |
| 체감 명암비 | `(투사 조도 + 주변광) ÷ 주변광` — 7:1 이상 권장(발표), 15:1 이상 우수 |
| 멀티 분할 | `n ≥ (전체폭/대당폭 − 오버랩) ÷ (1 − 오버랩)` |

> 실제 기기의 루멘은 컬러 모드·램프 사용 시간에 따라 정격보다 낮게 나오므로,
> 안전율 20~30%를 두고 계획하는 것을 권장합니다.
