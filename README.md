# ProMapper — 웹 기반 프로젝터 매핑

MadMapper의 **프로젝터 매핑(서피스 워핑) 기능**에서 영감을 받아 만든 경량 웹 매핑 도구입니다.
설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

```bash
# 방법 1: 그냥 index.html을 브라우저로 열기 (Chrome/Edge 권장)
# 방법 2: 로컬 서버 (권장 — 일부 브라우저의 file:// 제한 회피)
python3 -m http.server 8000
# 이후 http://localhost:8000 접속
```

## 주요 기능

| 기능 | 설명 |
|---|---|
| **쿼드 서피스** | 4코너 코너핀 — 정확한 투시(호모그래피) 워핑 |
| **메시 서피스** | 최대 12×12 컨트롤 그리드 워프 (곡면/비정형 표면용) |
| **입력 편집** | 소스 미디어에서 사용할 영역을 사각형으로 지정 (MadMapper의 Input 편집과 동일 개념) |
| **미디어** | 이미지·비디오 파일 + 내장 테스트 패턴 (그리드/체커/컬러바/그라디언트/화이트) |
| **테스트 패턴** | 코너 색상 마커(좌상 빨강 → 시계방향 초록/파랑/노랑)로 방향 식별 |
| **엣지 블렌딩** | 서피스별 상/하/좌/우 소프트 엣지 (멀티 프로젝터 오버랩용) |
| **색 보정** | 불투명도, 밝기, 대비, 채도, 틴트 (서피스별) |
| **출력 창** | 프로젝터 모니터로 드래그할 수 있는 별도 창, 더블클릭으로 전체화면 |
| **프로젝트 저장** | JSON 파일로 저장/불러오기 (이미지는 임베드, 비디오는 재연결 필요) |

## 사용 흐름

1. **프로젝터 출력 창** 버튼 → 새 창을 프로젝터 화면으로 드래그 → 더블클릭(전체화면)
2. `+ 쿼드` 또는 `+ 메시`로 서피스 추가
3. 테스트 패턴(그리드)을 띄운 상태에서 코너를 드래그해 실제 투사면에 맞춤
4. 미디어 패널에서 파일 추가 → 서피스 선택 후 미디어 클릭으로 할당
5. **입력 편집** 탭에서 소스의 어느 부분을 쓸지 영역 지정
6. **저장**으로 프로젝트 보관

## 단축키

| 키 | 동작 |
|---|---|
| 클릭 | 서피스 선택 |
| 코너 드래그 | 워핑 |
| 내부 드래그 | 서피스 이동 |
| 방향키 / Shift+방향키 | 1px / 10px 미세 이동 |
| `Delete` | 선택 서피스 삭제 |
| 휠 | 줌 |
| 휠 클릭 · Space+드래그 | 패닝 |
| `F` | 화면 맞춤 |

## 기술 구조

- 순수 HTML/CSS/JS — 의존성·빌드 도구 없음
- WebGL 렌더링: 쿼드는 동차 텍스처 좌표(projective interpolation)로 정점 4개만으로 정확한 호모그래피 워핑
- 출력 창은 `canvas.captureStream()` → `<video>` 스트리밍 (편집 UI와 완전 분리된 클린 출력)

```
index.html        UI 레이아웃
css/style.css     다크 테마 스타일
js/homography.js  3x3 투시 변환 수학
js/patterns.js    테스트 패턴 생성기
js/renderer.js    WebGL 워핑 렌더러
js/app.js         상태/편집기/UI 메인 로직
```

## MadMapper와의 차이 (미구현)

이 도구는 프로젝터 매핑 핵심 워크플로우만 다룹니다. 다음은 포함되지 않습니다:
NDI/Syphon/Spout 입력, DMX/Art-Net, LED 픽셀 매핑, 3D 캘리브레이션(공간 스캐너),
베지어 곡선 워프, 다중 물리 출력 관리, 마스크 레이어, 미디어 재생 타임라인.
